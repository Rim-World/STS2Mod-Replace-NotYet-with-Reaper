## 1. 修复方案审视

### 1.1 `CacheMode.Ignore` 是否切断共享

已确认。Godot 4.5 的 `ResourceLoader` 只在 `CACHE_MODE_REUSE` 时查询 `ResourceCache`；`IGNORE` 分支调用 `set_path_cache()` 而不是 `set_path()`，后者才会把资源写入 `ResourceCache::resources`。`.ctex` 导入路径同样把 `cache_mode` 原样传递。因此模组纹理不会进入 Godot 资源缓存。

### 1.2 `IsInstanceValid` 对已释放纹理的语义

已确认。反编译当前安装的 `GodotSharp.dll`：`GodotObject.IsInstanceValid` 返回 `instance.NativeInstance != IntPtr.Zero`；`NativeInstance` 读取 `NativePtr`；`Dispose()` 在释放后把 `NativePtr` 置零。游戏 `AssetCache.DisposeAtEndOfFrame` 走的就是 `asset.Dispose()`，因此被释放的纹理会被判为无效，不会抛 `ObjectDisposedException`。

### 1.3 所有权

已确认。游戏的 `AssetCache.LoadAsset` 用 `Reuse` 取得实例 G，并把路径登记进 `_missedCacheAssets`；`UnloadMissedCacheAssets` 只释放 G。模组用 `Ignore` 取得实例 M，既不在 `_cache` 也不在 `_missedCacheAssets`，不会被游戏释放。

### 1.4 113 检视卡时序

已确认。检视界面每次重开都先 `UpdateVisuals`（读取 `Model.Portrait`，即 M）再 `SetPortraitTexture(BigPortrait)`；`AssetCache.GetAsset` 对失效实例会重新加载。用户报告的 `NCard.UpdatePortrait` 崩溃路径已覆盖。检视界面自身仍持有游戏实例 G，属于第 3 节残余风险。

## 2. 跨版本与跨 mod 审视

### 2.1 三版成立

- 新 DLL 对 `refs107` / `refs111` / `refs113` 与当前安装 113 的 `sts2` 成员引用均为 `missingTargets=0`、`unresolvedRefs=0`。
- 10 个 Harmony 补丁目标三版都存在。107 的 `PortraitPngPath` 是私有 getter，Harmony 2.4.2 的 `DeclaredPropertyGetter(nonPublic: true)` 可以解析。
- `AttackCommand.FromCard` 的运行时反射分派正确：107 用单参，111/113 用双参。
- 三版 `sts2.dll` 都引用 `GodotSharp 4.5.1.0`、`0Harmony 2.4.2.0`，目标框架 .NET 9。
- 三版 `SemanticVersion.TryFromString` 实现一致；`1.1.0` 合法，旧 `1.0` 会被判为非法并只记警告。

### 2.2 与现有 mod 无确认冲突

- CalculatedGamble / CorpseExplosion / Evolve / PhantomKiller / Recycle / Scrawl 等替换 mod 的 `CardModel.Portrait`、`PortraitPath`、`PortraitPngPath` 前缀都按自身卡型守卫；对 `NotYet` 返回 `true`，不写 `__result`。
- Revert 类 mod 对 `Type`、`TargetType`、`TitleLocString`、`Description` 的前缀同样有卡型守卫。
- BaseLib 的同名 getter 前缀守卫 `CustomCardModel`；`NotYet` 不匹配。当前活动 `mods/` 目录未安装 BaseLib。
- 没有任何已安装 mod 对 `NotYet` 打补丁。

### 2.3 pck 与清单

- pck 含 15 个语言目录，无 `ind`、`ara`；`RE_REAPER.title` / `RE_REAPER.description` 齐全；与 `export_presets.cfg` 的 `export_files` 一致。
- 清单 `version=1.1.0`、`min_game_version=0.107.1`、`dependencies=[]`、`has_dll/has_pck=true` 在三版都能正常解析。
