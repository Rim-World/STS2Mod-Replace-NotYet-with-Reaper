# 死亡收割（Reaper）替换 · 翻译审批文档

- 日期：2026-08-06
- 关联决策：`1.ADR/001-时候未到整卡替换为死亡收割.md`

> 对应 mod：ReaperReplacementMod（塔2 Not Yet「时候未到」→ 塔1 Reaper「死亡收割」）
> 原文来源：本地正版 STS1 `desktop-1.0.jar` 的 `localization/<lang>/cards.json`，键 `Reaper`。
> 说明：死亡收割没有附带任何 Buff（吸血是即时治疗，不产生状态），因此本文档**只含卡面文本**；
> 若实现过程中发现需要额外 Buff 文本，再补充审批。

## 转换规则（默认方案，用户已批准机制）

1. `!D!` → `{Damage:diff()}`（塔2 动态变量语法，基础 4、升级 6 自动变化）；
2. 去掉 STS1 原文尾部的 “NL Exhaust.” / “NL 消耗。”等句（塔2 会以关键词徽记自动渲染“消耗”）；
3. `NL` → 空格；
4. 方案 B 标点/空格清理：zhs 去掉“未被 格挡”等多余空格；zht/kor 补句号；tha 按语言习惯保持无句号；
5. esp 与 spa 写同一份内容，最终共 15 个语言目录。
