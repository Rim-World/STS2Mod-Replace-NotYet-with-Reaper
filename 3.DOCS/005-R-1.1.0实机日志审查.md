## 3. 第三方错误与新发现

### 3.1 Loadout 的 `Callable.From<Task>`（2 次，本次新增）

- 日志：`godot.log:1333`、`godot.log:1342`。
- 异常：`System.InvalidOperationException: The type is not supported for conversion to/from Variant: 'System.Threading.Tasks.Task'`。
- 来源：`Loadout` 0.6.1 的 `Loadout.UI.NLoadoutNativeFeedback`，反编译行 454：

```csharp
val2.TweenCallback(Callable.From<Task>((Func<Task>)(() => TaskHelper.RunSafely(FlashRelics(cardNode, result.modifyingModels)))));
```

- 机制：Godot 调用 `Callable` 时会把返回值转换成 `Variant`；`Task` 不能转换，于是记录异常。回调体本身已通过 `TaskHelper.RunSafely` 启动，异常发生在返回值转换阶段。
- 影响：日志错误，可能伴随卡牌反馈预览不完整；未导致崩溃，游戏继续运行。
- 归属：第三方 mod，不是本 mod。本 mod 的 DLL 不含 `Callable`、`Connect`、`ToSignal`、`CallDeferred` 引用；异常栈是 Godot 的委托蹦床，代码位置在 `Loadout.dll`。
- 建议：向 Loadout 作者报告；正确写法是把返回 `Task` 的 lambda 包成 `Action`，例如 `Callable.From((Action)(() => TaskHelper.RunSafely(...)))`。

### 3.2 Loadout 的 Illusion 补丁被禁用（警告）

- 日志：`godot.log:727`。
- 内容：`Loadout: CreatureCmd.Kill changed; player Illusion defeat delay was left disabled.`
- 归属：Loadout 的 `PlayerIllusionDefeatDelayPatch` 转译器未匹配 113 的 `CreatureCmd.Kill`，主动跳过补丁。
- 影响：仅影响 Loadout 的「玩家 Illusion 战败延迟」行为；与本 mod 无关。

### 3.3 DarvRelicPoolMod 回退（旧会话）

- 日志：`godot2026-11-14T18.57.44.log:1863`。
- 异常：`System.ArgumentException: Value does not fall within the expected range.`，发生在 MonoMod JIT hook 与 `DarvRelicPoolMod.VanillaFallbackPool.Generate`。
- 处理：mod 捕获后回退原版池，游戏继续。
- 当前 1.1.0 会话未出现该错误（本局未触发对应事件）。

### 3.4 其它 mod 的版本号警告（低）

当前会话有 8 个 mod 的 `version` 是两段式，不是合法 SemVer：

`RevertRocketPunch`、`RevertTheSealedThrone`、`OstyDamageDetectionMod`、`ScrawlReplacementMod`、`CalculatedGambleReplacementMod`、`EvolveReplacementMod`、`RecycleReplacementMod`、`PhantomKillerMod`。

日志示例：`Mod RecycleReplacementMod declares version 1.1 which is not a valid Semantic Version`（`godot.log:524`）。

影响：加载器只记警告，`mod.version` 为空；与 Workshop 重复时按「未知版本」处理。当前这些 mod 的本地副本都正常加载。

### 3.5 RitsuLib 警告（低）

- `RuntimeReflectionMirrorSource` 枚举 `Steamworks.NET` 时跳过不可加载的 `OptionValue` 类型。
- 两条 `[Localization][DebugCompat] Missing localization key 'MOCK_...'`，属于调试兼容路径的占位键。
- 不影响游戏加载与战斗。

### 3.6 RandomForeseer 对本卡的预测不完整（提示）

- 日志：`godot.log:1351`：`No mirror is registered for OnPlay on MegaCrit.Sts2.Core.Models.Cards.NotYet; preview results may be incomplete.`
- 原因：本 mod 用 Harmony Prefix 短路 `NotYet.OnPlay`，RandomForeseer 的镜像表没有对应的新实现。
- 影响：该 mod 对「死亡收割」的伤害/吸血预测可能不完整；不影响卡牌实际结算。属于第三方预测 mod 的已知限制。
